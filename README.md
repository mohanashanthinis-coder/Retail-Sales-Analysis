# Retail-Sales-Analysis
Retail Performance & Customer Insights Analytics — an end-to-end retail analytics project that transforms transactional data into actionable business insights. The project analyzes sales performance, customer behaviour, product demand, store performance, and inventory health, with interactive Power BI dashboards highlighting key KPIs, customer segments, top-performing products, and business trends. It demonstrates a complete analytics workflow from data preparation and SQL analysis to customer segmentation and business intelligence reporting.
